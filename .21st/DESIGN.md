# RoomCall design context

Home Assistant Web Components with inherited HA colors, typography and density.
Reuse `ha-card`, `ha-icon`, native accessible buttons and form controls. Preserve
compact/kiosk layouts; retain Talk/Type/Ask at every size (behind More in the simple
layout, which new cards use). Use a separate modal
settings surface with keyboard-accessible tabs, a single active-plan test flow,
44px touch targets, relative type sizes and container-driven columns. New copy is
served from the integration translation catalogs. Microphones require local user
interaction. The 21st catalog was unavailable without authentication.
